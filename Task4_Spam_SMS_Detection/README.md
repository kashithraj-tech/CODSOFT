# 📩 Smart Spam SMS Detection System

## 📌 Project Overview

The Smart Spam SMS Detection System is a Machine Learning application developed as part of the **CodSoft AI Internship**. It classifies SMS messages into **Spam** or **Legitimate (Ham)** using Natural Language Processing (NLP) and Machine Learning techniques.

The project uses **TF-IDF Feature Extraction** with **Logistic Regression** to accurately detect spam messages. A professional **Streamlit** web application allows users to analyze SMS messages in real time.

# 🚀 Features

- 📩 Detects Spam and Legitimate SMS

- 📊 Spam Probability Meter
- 📈 Message Statistics

# ▶️ Installation

Clone the repository

```bash
git clone https://github.com/yourusername/Task4_Spam_SMS_Detection.git
```

Go to project folder

```bash
cd Task4_Spam_SMS_Detection
```

Install dependencies

```bash
pip install -r requirements.txt
```

Train the model

```bash
python train_model.py
```

Run the Streamlit application

```bash
streamlit run app.py
```
